# Design System

**Холбоос:** [app_flow.md](./app_flow.md)

---

## 1. Чиглэл

Тайван, төвлөрсөн, урамшуулдаг сургалтын орчин. Практик, итгэл төрүүлэхүйц; хүүхэд шиг эсвэл хэт тоглоомжсон биш.

## 2. Зарчмууд

1. **Ярих нь гол үйлдэл.** Ярианы товч/талбар үргэлж хамгийн тод, хүрэхэд хялбар.
2. **Алдаа бол шийтгэл биш.** Хэрэглэгчийн хэлний алдааг **улаан өнгөөр, "Буруу" гэж хэзээ ч** харуулахгүй. "Илүү сайн хувилбар" гэж харуулна.
3. **Эх, засвар, тайлбарыг ялгаж харуулна.**
4. **Нэг дэлгэц — нэг гол үйлдэл.**
5. **Ахиц харагдана.** Бага ахицыг ч тэмдэглэнэ.
6. **Монгол хэл эхэнд.** UI монгол; англи суралцах агуулга тод ялгагдана.

## 3. Өнгө

Token-ууд `src/app/globals.css`-д CSS хувьсагч (light + dark). Dark горим үйлдлийн системийн тохиргоог (`prefers-color-scheme`) дагана; гараар солих товч MVP-д байхгүй. Contrast-ыг `npm run check:contrast` (ба `npm test`) шалгана — M1-д текстийн бүх хос WCAG AA (≥ 4.5:1) давсан; хамгийн бага нь light `primary` / `background` 4.94:1.

`--border` (1.18–1.45:1) нь зөвхөн чимэглэлийн хүрээнд. Input-ийн хүрээ тусдаа token-тай (WCAG 1.4.11, ≥ 3:1):

|---|---|---|---|
| `--input-border` | `#64748B` | `#6B7280` | Light 4.55 / 4.76 · Dark 3.91 / 3.56 |

| Token | Light | Dark | Хэрэглээ |

| `--primary-foreground` | `#FFFFFF` | `#0B1020` | |
| `--background` | `#F8FAFC` | `#0F1115` | Хуудас |
| `--surface` | `#FFFFFF` | `#181B22` | Карт |
| `--text` | `#0F172A` | `#E9ECEF` | Үндсэн текст |
| `--text-muted` | `#475569` | `#9CA3AF` | Туслах текст |

- Текст ба дэвсгэрийн ялгаа ≥ 4.5:1 (WCAG AA).
- Төлөвийг зөвхөн өнгөөр илэрхийлэхгүй — icon, текст хамт.

## 4. Фонт ба зай

- Inter (`next/font`, self-hosted). Монгол Ө/Ү нь `cyrillic` биш `cyrillic-ext` subset-д байдаг тул `latin`, `cyrillic`, `cyrillic-ext` гурвыг ачаална; E2E тест Ө/Ү-г хамарсан фонт ачаалагдсаныг шалгана.
- Хэмжээ: гарчиг 24/32, дэд гарчиг 20/28, үндсэн 16/24, **чат 17/26**, жижиг 13/18.
- Зайны шат: 4, 8, 12, 16, 24, 32, 48 px.
- Хажуугийн зай: 16px (утас), 24px (таблет+).
- Radius: 8 / 12 / 16 px; chip ба гол товч бүрэн дугуй.
- Хүрэх талбай ≥ 44×44 px.
- Тайлбарын мөрийн урт ≤ ~70 тэмдэгт.

## 5. Компонентууд

| Компонент | Төлөв / тайлбар |
|---|---|
| `Button` | primary, secondary, outline, ghost, destructive; default, hover, focus, disabled, loading |
| `Input`, `Textarea` | default, focus, error, disabled; label заавал |
| `Card`, `Badge`, `Dialog`, `Toast`, `InlineAlert` | |
| `Skeleton`, `EmptyState` | Өгөгдөлгүй / ачаалж буй үед |
| `MessageBubble` | AI (зүүн, `surface`) / хэрэглэгч (баруун, `primary` цайвар); хэрэглэгчийн мессежийн төлөв: илгээгдэж буй / хадгалагдсан, хариу ирээгүй + "Дахин оролдох". (AI мессежийн орчуулга хойшлогдсон) |
| `Composer` | Бичих талбар + Илгээх; илгээж байхад идэвхгүй; хариу хүлээгдэж буй эсвэл амжилтгүй мессеж байхад түгжигдэж шалтгааныг харуулна; тэмдэгтийн хязгаар (1000) |
| `HintSheet` | Доороос гарна: монгол санаа + 1–2 англи жишээ; өдрийн hint үлдсэн тоо |
| `WordMissionChip` | pending (саарал) / used (✓) / used correctly (`success` + ✓) |
| `StrengthCard` | Сайн хийсэн зүйл |
| `CorrectionCard` | Таны хэлсэн → Илүү зөв (`improve`) + тайлбар; `style` бол "Илүү байгалийн" шошго; "Үгсийн санд нэмэх", "Буруу засвар" |
| `ScenarioCard` | Нэр, түвшин, зорилго, төлөв (хийсэн / дараагийн) |
| `WordItem` | Үг, утга, төлөв badge (Шинэ / Танина / Ашигладаг) |
| `ReviewCard` | Урд: англи; ар: утга + жишээ; "Санасан" / "Дахин давтах" |
| `ProgressSummary` | Тоонууд + алдааны төрлүүд; "ойролцоо" шошго |
| `MobileNav` | Home · Зам · Үгс · Ахиц. Давталт — Home-ийн "Өнөөдөр" карт ба Үгс хуудаснаас; Өмнөх яриа — Home-оос; Тохиргоо — толгойн профайл icon-оос |

Ижил төстэй контролыг хуудас бүрт дахин бүү хий — хуваалцсан компонент ашигла.

## 6. Ярианы дэлгэцийн байрлал

- Утас: нэг багана; дээр сценари + word missions, дунд мессеж, доор Composer (гар гарахад ч харагдана).
- Компьютер: зүүн талд яриа, баруун талд word missions ба сценарийн үгс.
- Мессежийн өргөн хэт тэлэхгүй.

## 7. UX бичвэр

- Найрсаг, хүндэтгэлтэй — "Та".
- Урамшуулах: "Сайн байна!", "Өмнөхөөсөө урт өгүүлбэр хэллээ."
- **Хэрэглэхгүй:** "Буруу", "Алдаа гаргалаа", "Муу".
- **Оронд нь:** "Ингэж хэлбэл илүү зөв", "Сайжруулах зүйл", "Илүү байгалийн хувилбар".
- AI-ийн засварыг үнэмлэхүй үнэн гэж бичихгүй ("AI-ийн санал" гэж тэмдэглэж болно).
- Товчны текст үйл үгээр: "Ярьж эхлэх", "Дуусгах", "Дахин оролдох".
- Бүх текст `messages/mn.json`-д.

## 8. Хүртээмж

- WCAG 2.1 AA.
- Focus үргэлж харагдана; dialog focus-ыг удирдаж, хаахад буцаана.
- Semantic heading, landmark.
- Icon товч бүрт монгол `aria-label`.
- Асинхрон төлөвийн өөрчлөлтийг (AI хариу ирсэн, алдаа) `aria-live`-аар зарлана.
- `prefers-reduced-motion`-ийг хүндэтгэнэ.
- Dark mode.

## 9. Хөдөлгөөн

- 150ms (жижиг), 250ms (sheet). Амжилтын анимаци зөвхөн ховор үйл явдалд (бүлэг дуусгах).

## 10. UI төлөв

Өгөгдөлтэй компонент бүр loading, empty, success, error, disabled төлөвтэй. Хуурамч товч, мухар дэлгэц байхгүй.
